Additional Parameters:

Power user feature: these values are applied last and sent exactly as written. Nothing is checked against the provider's API.
If the provider rejects a request, remove these first. They are kept per source and saved with Connection Profiles. Objects are merged into the request, so you only write the fields you want to change. To remove a nested field, use a dotted path such as generationConfig.thinkingConfig.
