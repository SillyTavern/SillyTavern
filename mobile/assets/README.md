# Asset Requirements

For a production build, you'll need to add the following image assets to this directory:

- `icon.png` - App icon (1024x1024 px)
- `splash.png` - Splash screen image (1242x2436 px recommended)
- `adaptive-icon.png` - Android adaptive icon (1024x1024 px)
- `favicon.png` - Web favicon (48x48 px)

For development and testing, Expo will use default placeholders if these files are missing.

You can generate these assets using tools like:
- https://www.appicon.co/
- https://icon.kitchen/
- Or create them manually in any image editor
